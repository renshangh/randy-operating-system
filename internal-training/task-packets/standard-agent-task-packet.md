# Standard Agent Task Packet

## Objective
State the exact goal in one paragraph.

## Deliverable
- exact file path(s)
- expected artifact type

## In Scope
- bullet list of allowed work

## Out of Scope
- bullet list of excluded framing/approaches

## Acceptance Criteria
- concrete list of what must be true

## Required Proof of Work
- exact file path changed
- summary of material changes
- how artifact satisfies acceptance criteria

## Non-Completion Rule
A status comment without a materially updated artifact does not count as done.
